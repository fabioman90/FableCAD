# FableCAD

FableCAD è un editor CAD 2D per il disegno tecnico, sviluppato con focus su macOS e Apple Silicon. Il progetto supporta il formato DXF e include un flusso di lavoro dedicato all’apertura e al salvataggio dei file DWG.

- [Release di FableCAD](https://github.com/fabioman90/FableCAD/releases)
- [Sviluppo per macOS, DWG e aggiornamenti](https://github.com/fabioman90/FableCAD/pull/3)
