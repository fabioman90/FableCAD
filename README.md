# FableCAD

FableCAD is a 2D CAD editor for technical drawing, with a focus on macOS and Apple Silicon. It supports DXF and includes a dedicated workflow for opening and saving DWG files.

- [FableCAD releases](https://github.com/fabioman90/FableCAD/releases)
- [macOS, DWG, and updater development](https://github.com/fabioman90/FableCAD/pull/3)
